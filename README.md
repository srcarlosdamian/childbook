# Childbook

Rediseño exploratorio del sitio de Childbook.ai y sistema de diseño independiente, construido con Vite.

## Rutas

- Sitio: `/childbook/`
- Sistema de diseño: `/childbook/design-system/`

## Desarrollo

```sh
npm install
npm run dev
```

Build para GitHub Pages: `npm run build`.

La configuración usa `base: '/childbook/'` para publicar como sitio de proyecto de GitHub Pages. Habilita Pages desde GitHub para el repositorio `childbook`.
